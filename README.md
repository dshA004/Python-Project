🎰 Python Slot Machine

A terminal-based slot machine simulator built in Python. 
Deposit virtual money, choose how many lines to bet on, and see if you win
— all through a simple command-line interface.

🎮 How It Works
1. You start by depositing a virtual balance.
2. Choose how many lines you want to bet on (1–3).
3. Place a bet per line (between $1–$100).
4. The slot machine spins and generates a random 3x3 grid of symbols.
5. If a row matches across all columns,
    you win — payout depends on which symbol landed and your bet amount.
6. Keep spinning until you quit or run out of balance.


🧠 Skills Demonstrated
- Core Python fundamentals (functions, loops, conditionals)
- Input validation and error handling
- Working with dictionaries and lists
- Randomization logic (random.choice, weighted symbol frequency)
